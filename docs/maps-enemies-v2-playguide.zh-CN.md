# 换位猎手 MapV2 游玩指南

**版本标识：MapV2；基础应用版本0.6.0；玩法规则版本5。**

这版围绕“先判断位置，再改变交火关系”组织十二章。枪械处理威胁，Q交换双方位置，场地机关改变通路与射线；完成明确目标并击败本章小Boss后即可撤离。普通敌人不需要全清。

## 启动与存档

完整解压Windows包后保留整个目录，不能只复制`SwapHunter.exe`。

- **正常成长：**双击`SwapHunter.exe`。使用普通v6成长档；既有章节、职业、武器和永久技能继续保留。旧v4/v5档仍使用独立迁移预览工具，不会自动导入。
- **快速展示：**双击`快速体验.cmd`。进入独立四职业演示整备页，可以选全部章节、全部枪械和六种刀。技能等阶与物资属于展示预置，不是实际通关成果。演示档每次启动单独创建在临时目录，不能用它替代正常成长存档。
- **指定演示：**在PowerShell中运行`开始演示.ps1 -Level 5 -Class 0 -Skill 1 -Menu`。章节为1—12；职业0—3依次为突击、重装、侦查、远程；Skill为该职业两项技能中的0或1。
- **Unity工程：**源码包导入Unity Hub时选择`Game`目录，使用Unity 6000.3.25f1。

首次体验推荐先玩第1章学习换位与交互；展示系统联动可从第5章开始。大图中的固定锚点、永久楼梯与维护路线提供返程，敌人不是唯一交通工具。

## 默认操作

按键可以在设置中更改；已保存的自定义绑定优先于下表。

| 操作 | 默认输入 | 使用方式 |
|---|---|---|
| 移动、冲刺、慢走 | WASD、左Shift、左Alt | 先用掩体与维护通路缩短暴露，再决定换位 |
| 跳跃/翻越、蹲伏 | Space、左Ctrl | 站稳跳板后重新按Space；仅走上跳板不自动发射 |
| 相位换位 | Q | 三维范围50米；必须有真实视线、合法双端落点，且两端不在有效干扰场中 |
| 枪械开火、瞄准、装填 | 鼠标左键、右键、R | 拿到补给不等于枪已装填；机械动作完成后才能正常继续开火 |
| 主枪、副枪、近战槽 | 1、2、3 | 槽3为持有的近战刀；关内拾刀只替换此槽，不改变职业和通用技能 |
| 近战 | 持刀左键/右键；V快捷近战 | 左键轻击、右键重击；近战刀与可召回的相位飞刀是两个系统 |
| 检视 | H | 检视当前装备，不提交伤害或物品奖励 |
| 通用盾、投刀、回刀 | C、G、X | 由出发时选定的通用技能决定可用项；A盾与相位飞刀二选一 |
| 职业技能 | Z | 出发前二选一；战术推进不会因击杀、命中、Q、拾取或Boss转阶段刷新冷却 |
| 交互 | E | 主任务终端按住0.6秒，撤离按住1.2秒；离开、切枪、开火或Q会取消未完成的交互 |
| 拾刀 | 靠近握柄后E | 需要约0.8米内并能真正伸手触及；按提示靠近或调整角度 |
| 战术背包 | Tab | 查看本次携带物品与状态 |
| 选择/切换道具 | 4、滚轮 | 进入道具选择后，滚轮在已携带道具间切换 |
| 使用道具/快速医疗 | T、F | T使用所选道具；F直接尝试医疗。无库存或当前无收益时不会扣道具 |
| 无线电与剧情 | F9、F10、Enter、Esc | F9跳过当前无线电句，F10回看通讯；剧情卡Enter继续、Esc关闭 |
| 暂停 | Esc | 暂停与整备不推进剧情中的灾难时间 |

### 换位、跳板与屏障

Q交换的是双方位置，身份、朝向、生命和装备仍属于原角色。失败不会把任务算作已到达，也不会扣成功冷却。先把准星朝向准备好，交换后不会自动转身瞄准敌人。

跳板投送的**水平距离是20米**，可能落到不同高度；它可以重复使用。持续按住Space落回跳板不会自动再次触发，松开后重新按下才是新的输入。空中Q会结束原跳板投送，不叠加残留强制位移。

A盾落地后保持世界位置与朝向，对双方弹道使用同一方向规则。部署者被Q或死亡，不会让盾跟着移动、翻面或提前消失。侧翼、真实墙体和地面危险仍要分别处理。原盾卫的实体盾属于随身装备，不能套用A盾规则。

### 装填、补给与六种刀

装填存在“弹药已经装入”和“枪械已完成机械收势”的区别。弹匣插入确认后弹药只结算一次；Q、切枪或持刀时保留应保留的装填阶段，返回枪械后继续。泵动霰弹逐发装填；栓动、泵动等机械循环完成前不能靠重复输入跳过节奏。

- **场地保障柜：**每柜每次行动只取一次，将当前两枪备弹补到行动上限，不直接填弹匣；备弹已满时保留柜子。标明医疗的保障柜另外恢复30生命。
- **消费道具：**医疗包恢复40生命；弹药包为两枪各补两弹匣的备弹，受各自上限约束；应急护甲提供40临时护甲。已有护甲、满血、满备弹或无库存时，不会无效消耗。
- **关内持刀：**普通匕首、M9宝石刀、爪子刀、蝴蝶刀、系绳匕首、锯齿刀具有不同实体轮廓。走近握柄触发拾取，实际抓握时才转移物品；提交前取消仍留在世界中，提交后取消保留已取得的刀。
- **永久拥有：**本次拾到的刀在**成功结算后**入库；失败或放弃不会提前解锁。重复取得同一实例不能复制奖励。演示档中的六刀是独立预置，不写入正常档。
- **相位飞刀：**同时管理三把飞刀，可投出并召回；每把刀每段对同一对象只结算一次，墙与实体盾真实阻挡。普通小怪的有效身体命中适用处决，精英、小Boss与最终Boss走自身伤害规则，不会被普通处决跳过。

## 四职业怎样与地图配合

| 职业 | 两项职业技能 | 在新地图中的使用思路 |
|---|---|---|
| 突击兵 | 战术推进 / 快速机动 | 利用短暴露段、侧巷、敌人收势接近侧背；快速机动仍会因攻击结束 |
| 重装兵 | 阵地加固 / 快速装填 | 先取得有侧后退路的可靠阵地，再维持输出；地波和热区仍需离开 |
| 侦查兵 | 战术扫描 / 精确射击 | 从观察窗、相邻楼层辨认支援单位与设备，再选择接近顺序；扫描不提供隔墙Q |
| 远程兵 | 遥控爆破 / 区域封锁 | 利用真实入口、落脚台和固定预告位置设置危险，再用Q改变危险承担者 |

职业武器池、双枪、职业技能与通用技能在关外选择，出发后锁定。地图机关不要求某个职业或某件消费道具才能通关。枪械与直接攻击按新伤害起算规则处理，但敌人也更耐久；优先争取有效射角和弱点窗口，没必要把整张地图的非指定敌人都消耗掉。

## 十二章路线与指定威胁

普通预算是整章最多可投入的计划成员，按区域与预警分批出现；不是并发数，也不是本局必须击杀的数量。未访问分支、成功断援和Boss击败后的合法取消会减少实际出场人数。

| 章 | 空间特色与主任务 | 普通预算 | 本章小Boss与处理重点 |
|---|---|---:|---|
| 1 相位校准 | 白蓝检疫庭院、分开的五个训练站、复核作业层；一次真实Q与指定实战目标 | 10，含5台非必杀训练机 | 校准监理：看世界锁定的脉冲位置，横移或换位离开，再利用转身窗口 |
| 2 盾线缺口 | 砖石检查街区、两段盾线、可进房屋、屋顶巡检线与双门消防检修院；解决两名指定盾卫 | 15 | 闸门执法官：侧巷绕盾，闸杆落下时走另一侧或操作手柄 |
| 3 垂直通路 | 封闭冷却井与逐层检修环；取得上层通行件 | 15 | 升井监察机：利用永久楼梯、高差与中央冷却芯躲扫束 |
| 4 首次撤离 | 夜间货运站、真实轨道货车、连桥调度室；凭据开启中央捷径 | 20 | 站场壁垒官：争取屏障背面，利用台车和车厢断开点射 |
| 5 交叉火网 | 不等高双塔、雷达机房与装车场；双火控节点顺序自由，各自开对应遮蔽路 | 30 | 双塔校射官：分次处理交叉预警，观察转场落点；R-S中继与设施取舍仍保留 |
| 6 危险转移 | 连通罐组、管廊、维修沟与泄压支路；真实破坏两处封锁装置 | 30 | 泄压炉卫：热区留在世界原位，用阀门、绕路或Q转移风险 |
| 7 三岛继电 | 岩岸、低层永久维护桥、0/8/16米任务层；搬锚完成三处接入，顺序自由 | 25 | 断桥牵引者：先看索座与安全通道；Boss不会回滚接入与已经开启的桥 |
| 8 回线仓区 | 中央分拣厅、近距堆垛A仓、长线B仓、高架C仓、上层巡检线和双门冷机检修间；任取两匣 | 30 | 分拣执行官：数据选择决定仍在工作的辅助模块；第三仓仍为可选 |
| 9 高塔回收 | 悬崖通信台地，从32米顶层取核心后逐层下撤；无需清理上层遗留敌人 | 40 | 巡天猎隼：看俯冲落点，在落地恢复期争位，使用维修台与冷却风罩 |
| 10 持续封锁 | 矿料堆、皮带机和不对称三站环路；关闭对应部署入口 | 45 | 运输督导：抢站降低后续压力，道岔改变可用冲撞路线；不会恢复已取消预算 |
| 11 反相设施 | 玻璃实验室、外环与地下维护线；取得权限，固定干扰器可分别关闭 | 35 | 反相审查者：拆信标或离开局部场，保留枪战与外环走法 |
| 12 核心突破 | 前置隔离厅、独立补给准备区、多层反应炉与永久避险台 | 30 | 先击败相位门卫，再进入原最终Boss战；双授权后取核心，最终Boss也须击败 |

合计**325名普通计划成员＋12个独立小Boss＋1个最终Boss＝338个最大计划对象**。第12章普通预算为前置10名、最终战三个阶段合计20名，不能把每个阶段误读为20名。

第10章的增援倒计时从进入对应警戒区开始，先有准备时间，再有4秒入口预警。关站取消未触发和预警中的成员，已经落地的敌人不会消失。本版没有旧地图的开局备弹减半惩罚，站内有明确保障柜。

## 14种敌人原型的辨认

| 原型 | 先观察什么 | 常见应对 |
|---|---|---|
| 训练机 | 校准标识与静止位置 | 用于学习Q和命中；不计入撤离必清 |
| 突击兵 | 举枪、瞄准与短点射 | 断线后换位，争取侧向射角 |
| 狙击手 | 真实预告射线与射后间隔 | 利用掩体，处理与其相连的支援设备 |
| 原盾卫 | 实体盾的朝向与露出的身体 | 绕侧、争背面，避免把盾击误认作扣血 |
| 战术精英 | 加强装备与可见组件 | 普通枪械持续伤害；不能用普通小怪处决规则跳过 |
| 屏障射手 | A盾部署方向、后方与侧面开口 | Q夺盾后位，或从另一通道绕过 |
| 跃袭追猎者 | 蓄力姿态与预告落脚点 | 离开落点，在落地收势时反击 |
| 破障冲击兵 | 锁定冲撞方向、标明可破的隔断 | 侧移或诱导开路；永久承重结构不会被随意拆掉 |
| 曲射掷弹兵 | 实体曲射弹与世界落点 | 走出爆炸范围，或在时机合适时换位 |
| 维修工兵 | 正在接近的发生器或设备 | 截断维修路径、优先处理组件支援 |
| 标记侦察机 | 观察方向与标记准备 | 破坏侦察信息链，利用真实遮挡 |
| 反相干扰员 | 局部信标与边界 | 拆信标、离开边界，不能把它当作全图禁用Q |
| 牵引控制者 | 索的来源、连接线与柱体 | 用柱体切断关系或选择另一条通路 |
| 架设压制机 | 架设岗位、压制扇区与收势 | 从侧后接近，避免在它锁定方向内长时间站立 |

每章小Boss是上述职责的场地化组合，有自己的名称、模型结构、预告与反制窗口。它们可以正常受枪械伤害；短暂打断抗性不等于永久免疫。

## 一条连贯的展示路径

1. 在独立演示整备页选定职业、双枪和通用技能，说明为什么选择这套组合。
2. 进入第5章，先辨认两塔、地面维护路线、近端补给与R-S关系。选一个节点作为先手目标。
3. 用真实楼梯或合法Q取得更好的射界；解释“换到哪里”和“把敌人送到哪里”是同一个决策的两面。
4. 操作第一个火控点，观察相应通路与敌人响应；再处理另一塔。
5. 在双塔校射官战中利用两条接近路线、断线设备和预告间隔，完成明确威胁后撤离。
6. 展示结算、通讯记录与刀具成功入库；最后切到第7章或第8章，说明自由接入顺序、三选二如何改变空间和后续战斗。

剧情主线《归航行动》保留章节简报、无线电、转折卡与结局。声音包含既有免费许可音乐和音效；中文故事通过字幕与通讯记录呈现，没有人物中文配音。
