# v0.6 十二关任务与遭遇

本轮把“换位”从统一的跨断口步骤，扩展到朝向准备、射界争夺、危险转移、锚点搬运和撤离取舍。下表对应当前 [任务资产](../Game/Assets/_SwapHunter/Resources/MissionConfiguration.asset) 与 [地图布局](../Game/Assets/_SwapHunter/Scripts/ExpeditionLayouts.cs)，是实现说明，不是已测通关、平衡或真人路线多样性的报告。执行证据见[验收记录](validation.zh-CN.md)。

章节内部 ID 仍为 0—11，界面显示 1—12；首通解锁和永久成长索引保留。总预算包含尚未触发、预警中和已部署成员，不等于同时在场人数。“可遗留”只说明撤离条件，不代表敌人停止攻击。

## 1—4：把位置转化为任务收益

**1 相位校准。** 安全校准区与侧台实战区分开。训练机在入场后部署；只有已成功 Q 且访问实战区，才触发实战守卫。玩家可夺取侧台后转身射击，也可先走地面侧路，再利用锚点调整角度。训练机提前死亡仍有锚点完成校准；侧台有永久楼梯，前方门在指定守卫解决后打开。补给放在安全区，本关无可选数据。

**2 盾线缺口。** 第一盾卫面向入口；第一场解决且第二场区域已被访问后，部署守出口的盾卫和侧向突击兵。左半环路与右检修回路提供不同源位置：可诱近盾卫、横移后换位，也可先处理侧向火力再换盾。收益来自交换前的站位和保留朝向，不是自动背刺。两场之间和后段各有补给；侧向突击兵不是撤离必清。

**3 垂直通路。** 低位、中层、上层三名突击兵分组触发；平台为 2.2/3.3 米。上层通行件与出口让登高直接推进任务。可沿楼梯逐层接近，也可用低通道/翻越或一次性大跳取得换位视线。大跳耗尽、敌人被杀、锚点搬走后仍保留楼梯；不是要求普通腾空中连续完成两次 Q。

**4 首次撤离。** 前段是一盾一突；核心凭据位于中央门前，拿到后开放前方捷径，并从侧入口预警部署两名截击突击兵。玩家此时可选择中央短路，或沿左右外环绕行再到对侧出口；锚点也可用于脱战。普通敌人无需全清。可选数据位于暴露侧台，风险是绕路、停留与现有射线；拾取本身不再额外刷统一追兵。

## 5—8：组合射界、危险与路线

**5 交叉火网。** 左塔 4.4 米、右塔 3.3 米，两名狙击手有固定高位、不同初始朝向及错开的启动/预警；另外有两名塔根突击兵和中央盾卫。取得第一个节点再触发一名侧方突击兵。每个节点只打开对应遮蔽通路，双节点才满足主任务。可先夺一塔建立射界，也可沿楼梯和遮蔽路线逐座推进。两塔都保留步行入口；非法高位部署延期，不把狙击手降到地面。可选数据位于远端绕行位置，增加路线长度与暴露。

**6 危险转移。** 三组各两名突击兵：第一组入场，第二组在装置 A 完成后触发，第三组在装置 B 完成或先访问侧仓时触发。第一组的一名成员带真实投雷提示逻辑，仅在距离、视线、沉默和当前状态允许时投出真实手雷，危险不会跟着换位搬走。装置 A/B 的当前生命为 96/144；实际枪击、爆炸和近战均可破坏。可利用手雷落点与 Q 改变危险承担者，也可从掩体边接近并直接破坏。枪弹耗尽仍有近战与绕行退路；侧仓数据可能提前引入第三组交战。

**7 三岛继电。** 三个接入座顺序自由，任务锚点可搬运，接入完成后桥路锁存。初始预算分布在 B/C 岛，完成两个接入后再触发两名突击兵。玩家可站在接入座上把远处锚点换入，也可先走下层维护路改变源站位再搬锚。下层路径位于约 −3.3 米，有回到各岛的楼梯；维护终端显式复位任务锚点。复位检查原位净空，不把人物挤开，也不撤销已接通桥路或刷新奖励。

**8 回线仓区。** A 仓为近距盾线，B 仓为长射线，C 仓为折返掩体；各分支两名敌人。首次到达或向可见分支开火都会锁存访问并激活预算；隔墙射线不算访问。前后贯通路线和两处真实视线窗允许在仓区间调整位置。任选两匣即满足主线；界面显示主目标 2/2，第三匣另列为额外目标 0/1 或 1/1，成功带出额外 +40。取第三匣不会把主目标写成 3/2。可以按现有配装选两条分支，也可承担第三分支的路线与交战成本；未研究回刀照样能够完成主任务。

## 9—12：在压力中选择何时离开

**9 高塔回收。** 玩家从顶层开始，取得核心后向地面撤离。初始顶层为一狙一突；携核心进入中层和下层区域时，分别触发后两组截击。可用永久楼梯缓慢下撤，也可利用 6.6/4.4/2.2 米平台和锚点缩短暴露路线。Q 或跳跃落入区域也会触发，回头不重复刷同组；上层活敌和未触发非指定预算不堵出口。可选数据在顶层侧路，会增加停留和下撤风险。

**10 持续封锁。** 初始一盾两突，左/右/后入口各两名有限增援，触发时间为行动游戏时钟 15/30/45 秒，每组预警 4 秒。关闭控制站取消对应尚未生成的成员，包括已开始预警者；已落地敌人继续存在。可先处理近站减少未来压力，也可利用掩体与换位直取后站，再回收两侧。初始备用弹药减半、弹匣仍满，仅一处场地补给。不是无限刷怪生存关；无需清空九名预算才能撤离。

**11 反相设施。** 左右各一处半径 6 米的固定局部干扰球，控制器独立可步行到达，发射器也可受击摧毁。Q 同时检查玩家与目标脚部是否入场；瞄准射线穿过场区中部本身不禁 Q。可以沿场外外环取得权限后撤离，也可以关闭一侧局部场建立短路；不要求关闭两场。三组敌人按区域访问触发，核心权限是唯一主目标；可选数据位于另一处干扰区内，增加渗透风险。

**12 核心突破。** Boss 从地面合法入口开始；三个随从组分别绑定 Boss 就绪、步枪、半血组合阶段，合计四突一盾一狙，预警与存活随从合计最多两名。两处授权位于 3.3/4.4 米平台，核心在地面；授权先后自由。可先沿永久楼梯取得高位，也可保留大跳/Q 在 Boss 技能压力中争位。Boss 死亡取消未部署随从，已经出现的随从可遗留。

本关有三处一次性大跳，以及三处 1.4 米永久避险台：两处位于场内，另一处位于左侧外环；低台保留多个坡道入口，并用侧缘护栏与对应导航边界引导真实上坡。相位行动第 12 关撼地波预警为 2.5 秒，传播速度仍为 12 米/秒，原生基础伤害保持 26。地波命中判断与脚部相对地面高度有关，A 盾无效；不能把普通跳跃或“高台存在”直接当作慢配装已通过的证据。

## 必须保留的验收边界

每关应分别确认目标状态、预算变化和真实可达路线。程序注入坐标/目标的状态检查，只能证明相应状态转换；它不能代替角色沿碰撞体走完路线。

| 场景 | 需要观察的结果 |
|---|---|
| 关键敌人提前死亡、锚点移走、大跳耗尽 | 必需路线仍可走；指定威胁和目标状态不会错误卡住出口 |
| Q/跳跃越过入口、回头再进入、改变目标顺序 | 区域能触发且锁存；同一预算不重复生成或重复发奖 |
| 非指定预算未触发、预警中或非法落点延期 | 允许遗留的关卡仍按主目标和指定威胁判断；不把全局待部署数当门锁 |
| 关闭入口或 Boss 死亡恰逢预警结束 | 未生成预算取消，活敌不被删除，不在下一帧补刷 |
| 两端中一端进入干扰、准备期间场区切换 | 使用最终复查结果；失败原因可定位到干扰场 |
| 锚点原位被占、装置重复受击/交互 | 复位拒绝且不搬玩家；接入、破坏与结算只完成一次 |
| 最慢配装行走、高台回撤和地波反制 | 真实走过楼梯、坡道和维护路；记录实际时间/失败位置，不以距离估算代替实测 |

慢配装夹具使用支援轻机枪、生存三级与扩容备弹，移动设置倍率保持 1，不额外降低基础移速。当前场景配置下，普通行走理论速度约为 3.266 米/秒；冲刺约为 4.709 米/秒。这些是配置公式值，不是路线均速或真人反应数据。

BossEscape 默认按 W+Shift 冲刺，并通过验证脚本加入固定 0.5 秒反应等待；可显式选择 Walk 或不同等待值，报告会记录实际参数。它预先根据全图 NavMesh 选路，采用明确摆放的起点和 Boss 阶段、移除随从、标记大跳已用；成功需观察到真实角色站稳在安全高度且没有被原生地波命中。它不覆盖真人找路、首次理解预警、所有可能起点或完整战斗压力，不能据此承诺任何站位都能在 2.5 秒内走到高处。

换位尝试/失败原因、两端位置、目标完成、区域访问、部署与取消、撤离资源等日志可支持定位。真人初见是否理解目标、是否主动准备 Q 源站位、为何选择某条分支，仍需真实试玩记录；当前不宣称已完成 6—8 人测试或已证明平衡改善。

具体实现入口见[架构说明](architecture.zh-CN.md)，玩家操作与资源规则见[游玩指南](playguide.zh-CN.md)。
