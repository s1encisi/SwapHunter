# 换位猎手 D2/N1 · 归航行动游玩指南

D2/N1 是本次“系统联动＋归航剧情＋声音”升级标识。应用版本仍为 **0.6.0**，战术规则版本为 **4**，成长存档继续使用 v6。请以交付包的 `开始阅读.md` 和构建身份识别本版本。

## 1. 解压后直接玩

完整解压 Windows 包，保留 `SwapHunter.exe`、`SwapHunter_Data`、Unity 运行库等文件在同一目录。无需安装 Unity。

- **正常成长**：双击 `SwapHunter.exe`，从正常游戏入口进入《归航行动》，按章节推进、采购与成长。
- **快速展示**：双击 `快速体验.cmd`，打开独立四职业演示整备页，可直接选择第5章体验系统联动，开场可从主菜单“开始归航行动”或整备“归航档案”阅读。演示预置装备与章节不代表真实通关，不写入普通成长档。
- **自定义演示**：`开始演示.ps1 -Level 5 -Class 0 -Skill 1 -Menu`。Level 为1–12，Class 为0–3，Skill 为该职业两种技能的0/1。

源码包需在 Unity Hub 中选择其中的 `Game` 文件夹，使用 **Unity 6000.3.25f1**。免安装 Windows 包与 Source 包是同一交付的不同用途，运行游戏不需要打开 Source 包。

## 2. 基本操作与剧情阅读

默认键位可在设置中查看和修改：WASD 移动，鼠标瞄准，左键开火，右键瞄准，Q 换位，R 装填，E 交互，1/2 切换双枪，C 定向屏障，V 近战，G 投刀，X 回刀，Z 职业技能，F 使用消耗品，Tab 背包，Esc 暂停。

本次剧情交互：

| 操作 | 作用 |
|---|---|
| 剧情卡中的 Enter / 下一段按钮 | 阅读下一段 |
| 剧情卡中的 Esc / 跳过阅读 | 关闭当前阅读，不改变主线完成条件 |
| 战斗时 F9 | 前进到下一句无线电字幕 |
| 战斗时 F10 | 打开本次通讯记录；阅读期间暂停行动 |
| 整备中的“归航档案”入口 | 查看已成功带回的章节记录与附件 |

无线电使用角色姓名、中文字幕和接通提示音，**没有中文人物配音**。可以边行动边阅读，也可以在安全位置打开通讯记录回看。商店、暂停和剧情卡没有全局灾难倒计时。

## 3. 主线在做什么

你扮演前相位救援员林越。起初是带回七号泊位旧案的调度凭据；第4章得知仍有312人被困后，行动转为恢复救援支路、切断后续增援、取得维护权限并停止清港。四职业是林越的四套作业配置，故事身份一致。

每章的关前简报说明任务缘由，推进真实目标会触发短无线电；第4、8、12章承接较完整的剧情转折。第5章塔路、第7章继电和第9章高处回望能看到救援路线的阶段性反馈。无需护送312个实体NPC，也无需清空所有敌人。

重要章节的自由顺序保留：

- **第7章：三岛继电。** 三个继电座可任意顺序完成，各自反馈通风、照明或救援通路；已记录的目标不会因锚点后来被搬走而撤销。
- **第8章：回线仓区。** 任意两匣都恢复同一条必要真相；第三匣补充班组附件，主线不要求全收集。
- **第12章：核心突破。** 根据现场状态处理授权、核心与Boss；可先解决Boss，也可先推进可达的授权目标。击败Boss本身不等于任务成功，仍需满足界面列出的主线条件并到出口撤离。

当前尝试中的通讯即时可回看；永久章节记录依据成功结算回执开放。失败、重试和退出不会提前发放成功奖励。可选附件补充人物信息，不改变救援主线结局。

## 4. 第5章：先观察系统关系，再决定处理方法

推荐第一次演示选择第5章“交叉火网”。两座塔的主线通路授权终端、出口和6名敌人预算保留；新中继与维护设施是围绕这条通路的可选决策。

### 观察左塔 R → S

左侧突击兵是发送者 **R**，背部有独立的火控设备；左塔狙击手是接收者 **S**。R与S都真实入场后，挂点相距不超过13米、连线无遮挡且R没有硬直或沉默，连续接入0.8秒后连接。连接保持上限为14米，墙、楼板和实体掩体会断线。

连接只加快S的**射后整备**：普通状态需要推进2.4秒工作量，持续连接时约1.8秒完成。狙击预告仍为1.2秒，最后0.32秒锁定瞄点。断R不会取消S已经开始的预告或飞出的弹丸，因此仍要尊重狙击红线与掩体。

可以将R换到塔板遮挡的一侧、让双方超距、用沉默/硬直压制R，或直接破坏设备。断线后的狙击整备保留已经完成的进度，重连重新要求连续0.8秒，不会重置整备或立即补发一枪。

### 保全设备，取得原有可选奖励

设备独立 **48 HP**，射中设备只伤设备，射中本体只伤本体。设备不会给R附加一条本体护盾。它大于0 HP时，击败R会落下一份可回收任务件；受过伤但尚未毁坏的设备仍可回收。

- 瞄准R身体处理载体，可以保全设备。
- 爆炸可能同时覆盖本体和设备；同次攻击先结完再决定掉落，不能假定爆炸必定留下设备。
- 设备归零会永久断开该中继并失去本次回收资格，不扣已有信用点，也不阻断主线。
- 接近掉落设备，保持2.8米内和视线，**按住 E 2秒**回收；松开或主动攻击会重置进度。
- 回收只记为本次可选成功，**成功撤离后结算原有 +40**；没有现场即时到账。它已替换旧远端可选数据，不会再额外叠加一个Bonus。

掉落物独立于尸体存在，尸体清理后仍可回收；掉落位置使用载体最后合法站立点，必要时回到预置可达位置。

### 中央锚点：掩护与补给二选一

搬运中央锚点到接入圈中，站近后**按住 E 1.5秒**确认，本次只能选一项：

| 输出 | 作用 | 适合考虑的情况 |
|---|---|---|
| 北向掩护 | 展开一处固定掩体，增加塔间转场遮蔽 | 补给充足，或者希望缩短暴露时间 |
| 南侧补给 | 医疗1份与弹药1份，各自独立领取 | 生命或双枪备弹有实际缺口，并愿意付出折返与操作时间 |

锚点进入圈只表示可以接入，不会自动选定。完成提交后选择锁存，搬走锚点不会撤销；另一输出关闭。展开范围有人或物阻挡时会拒绝提交，腾出空间后再试，不会把角色挤走。

本次将原左侧自动补给归并进南侧输出，保留右侧原补给，没有额外新增第三站。

### 有限补给怎样算

- 医疗最多恢复30 HP，一份；满血拒绝且保留份数，缺6点时只恢复6点，领取后该份用尽。
- 弹药向当前双枪各补一个有效基础弹匣的备弹，一份；每枪分别按当前备弹上限截取实际缺口，不自动装填。
- 两把枪都不缺备弹时不扣份数；某把枪原有备弹高于当前上限，不会因领取被削减。
- 它们是本次场地服务，不向永久仓库发道具，不自动刷新，不折算为现金。

新持E交互在战斗时间内进行。松开E、离开范围、失去视线、主动攻击、被接受的Q、换枪、装填或死亡会取消；无效Q不会取消。装填、蓄能、近战过程中按E不会排队延迟执行。屏障、扫描、精确准备和自用补给仍可用于保护或配合操作。暂停冻结交互进度。

## 5. 技能、敌人响应与短情境试用

D2把标记增伤统一到合格的玩家本体伤害来源：枪械、近战、飞刀、爆炸和区域伤害遵循同一标记结算规则。设备、自伤与环境损伤不享受载体标记；同一接收者的多个碰撞体不制造重复伤害。

敌人的换位响应围绕被交换对象和实际受影响的局部成员更新；可观察危险会参与局部位置选择。将R换走后，它可能沿合法路线尝试恢复连接，换位更接近持续改变交火关系，而非只争取一次硬直。

整备中的短情境试用可以集中观察“标记伤害对照”“换位断线”和“封锁改道”。不适用于当前商品的情境会禁用，不会偷换正在试用的技能。试用使用独立状态，结果不向正常成长档授予资产。Boss的空间选招在下一次起手时考虑现场空间，已开始招式仍按既定流程执行；不要把改变位置理解为能够随时取消已起手的攻击。

## 6. 声音设置与体验

3首完整外部配乐对应5种状态：菜单/整备、探索、普通交火、Boss、结局；其中菜单与探索共享 calm，交火与Boss共享 action，结局使用独立钢琴曲。探索和战斗双版本同步淡变，剧情无线电期间降低背景音乐以保留信息可读性。

另有17个精选音效和1段58秒水岸环境循环，覆盖枪响、爆炸、金属命中、脚步、相位/护盾、界面和无线电提示。设置中的总音量、音乐、环境、音效、反馈与界面音量继续分别生效；如无声，先检查对应滑条及窗口失焦静音选项。

素材作者、CC0原始来源及接入处理见 `THIRD_PARTY_ASSETS.md/json` 和 `SwapHunter_Data/StreamingAssets/ThirdParty/AudioN1/`。水岸环境声来自作者的维斯瓦河录音选段，不是虚构港口的实地录音。
