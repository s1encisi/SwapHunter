# 四职业玩法指南

正常启动进入独立的 v6 四职业成长档。旧章节 v4 档和 T01 v5 档保留，不会自动导入。最终构建和实测范围见[本轮验证记录](tactical-validation.zh-CN.md)。

## 正常开局

1. 在职业整备选择突击兵、重装兵、侦查兵或远程兵，领取该职业入门枪，再从它的两项职业技能中任选一项免费保障。全档卡宾枪只授予一次。
2. 从 A盾、相位飞刀中任选一项全档通用技能保障，装备两把不同、已拥有且符合当前职业资格的枪。
3. 新档是 0 信用点、0 道具。直接用保障配置部署首章；不需要先买补给，也不需要卡宾枪一直占一个槽。
4. 成功撤离获得信用点，再在关外采购、强化或调整下一次配装。武器、技能和库存由账户共享，每职业独立记住装备、配件和携带方案。

| 职业 | 专属枪池（卡宾全职业可用） | 入门保障枪 | 职业技能二选一装备 |
|---|---|---|---|
| 突击兵 | 泵动霰弹枪、紧凑冲锋枪、双管破门枪 | 泵动霰弹枪 | 震荡突击 / 快速机动 |
| 重装兵 | 重型突击步枪、支援轻机枪 | 重型突击步枪 | 阵地加固 / 快速装填 |
| 侦查兵 | 三连发步枪、精确射手步枪、栓动狙击枪 | 三连发步枪 | 战术扫描 / 精确射击 |
| 远程兵 | 弧线榴弹发射器、蓄能线圈枪、相位标记器 | 弧线榴弹发射器 | 遥控爆破 / 区域封锁 |

## 默认操作

| 输入 | 功能 | 输入 | 功能 |
|---|---|---|---|
| WASD / 鼠标 | 移动 / 观察 | 左键 / 右键 | 开火 / 瞄准 |
| Space / 左Shift | 跳跃、翻越 / 冲刺 | 左Ctrl / 左Alt | 蹲伏 / 慢走 |
| Q / E | 双向换位 / 交互 | R / 1、2、滚轮 | 装填 / 切枪 |
| Z | 当前职业技能 | C | 已装备的 A盾 |
| V | 基础近战，所有配置保留 | G / X | 已装备飞刀的投掷 / 召回 |
| Tab / Esc | 暂停背包 / 暂停菜单 | F | 使用医疗包 |

键位可在设置中重绑。弹药包、应急护甲通过 Tab 背包中的“使用”按钮操作；F 当前只对应医疗包。Q 是全职业共用动作，不占技能槽、不从商店购买：换位保留双方朝向，既有手雷和危险仍留在世界。任务看主目标、指定威胁和出口提示，普通活敌不一定需要全清。

## 技能与三级成长

所有职业技能基础均开局可购，同职业两项没有相互前置。以下数列依次是 1 / 2 / 3 级，来自当前 `ClassSkillTuning`。一场行动只带一项职业技能和一项通用技能；关内不能换职业或改配装。

| 职业技能 | 当前效果与升级 | 冷却 / 主要限制 |
|---|---|---|
| 震荡突击 | 前方4m、90°，普通敌人硬直0.6 / 0.8 / 1.0秒；无直接伤害 | 12秒；墙、实体盾阻挡；Boss仅打断步枪连射 |
| 快速机动 | 地面移速+25%，持续2 / 2.5 / 3秒 | 10秒；开枪、近战、投刀、引爆结束效果；允许Q，不增加跳高 |
| 阵地加固 | 固定半径3m阵地持续4秒，普通伤害减免15% / 20% / 25% | 16秒；须同层、无遮挡；离开失效、回来恢复；不减免地波等空间机制 |
| 快速装填 | 当前装填剩余时间减少30% / 40% / 50% | 14秒；先按R进入有效装填；不生成子弹，Q会中断未完成装填 |
| 战术扫描 | 20m内敌人当前位置和朝向显示3 / 4 / 5秒 | 12秒；可获得遮挡后的信息，不赋予隔墙Q能力 |
| 精确射击 | 4秒预备，下一发实际枪弹伤害+15% / 20% / 25% | 14秒；射空、命中盾也消耗，三连发只强化首发；职业预备允许Q |
| 遥控爆破 | 一枚装置，爆炸基准64 / 80 / 96，半径3m | 0.5秒后再按Z引爆；8秒超时失效；结束后冷却18秒；距离衰减、墙阻挡、有自伤 |
| 区域封锁 | 瞄准12m内地面，半径3m区域持续4秒，每秒16 / 20 / 24伤害 | 18秒；每0.25秒按同层实际停留结算，墙阻挡，也伤自己 |

非法使用会显示原因，不启动技能冷却；已经成功释放但没命中，仍按正常冷却处理。暂停会暂停游戏技能计时。精确射击的职业预备不是线圈枪自身蓄能，武器自身状态仍受 Q 的原检查约束。

- A盾三个等级都持续4秒，冷却依次10 / 9 / 8秒；屏障固定位置和朝向，侧背仍有风险。
- 飞刀1级具备投掷、召回和回程伤害；2级增加命中沉默，3级增加受墙遮挡的4m范围沉默。往程28、回程22，沉默3.2秒；同时只保留一把，实体墙/盾不能穿过。
- 通用槽的盾、刀互斥。未装备飞刀仍保留 V 基础近战；未装备盾不能按 C 临时获得它。

## 商店、道具与失败

| 道具 | 单价 | 使用效果 | 携带上限 |
|---|---:|---|---:|
| 医疗包 | 20 | 恢复40生命，生命满时不消耗 | 2 |
| 弹药包 | 25 | 双枪各补两弹匣的备弹量，受各枪备弹上限约束；备弹全满不消耗 | 1 |
| 应急护甲 | 25 | 获得40临时护甲；旧护甲未耗尽时不能叠加且不消耗 | 1 |

两道具槽必须是不同类型；可以空槽。携带设置是期望数量，实际带入取库存和期望的较小值。场地补给只作用于本关，不变成可带出的库存商品。用过的护甲包不会因为撤离时还剩护甲而返还。

武器开局上架卡宾、泵动、重突、三连发、榴弹；第三章后上架冲锋、轻机枪、射手、线圈；第六章后上架双管、栓狙、标记器。上架需要购买才拥有；可以买其他职业商品，但当前职业不能越权装备。技能基础100，升二级100，升三级160；配件在关外免费切换。首通总奖励从200逐章增加15，重玩基础50，可选成功带出另加40。可行采购顺序见[逐章经济路径](tactical-economy.zh-CN.md)。

出发快照在采购保存后建立。死亡重试恢复同一次出发配装和携带，保留尝试/死亡次数；主动退出不取消已完成采购，也不提交本关奖励或道具损失。只有成功结算才一次扣除本次实际消耗、发奖励和更新首通。保存失败会显示错误，不能把未保存结算当成功。

## 独立演示

从解压后的玩家目录运行；示例中命令参数与数值之间必须有空格：

```powershell
.\SwapHunter.exe -swapHunterTacticalDemo -demoLevel 5 -demoClass 0 -demoSkill 1
.\SwapHunter.exe -swapHunterTacticalDemo -demoLevel 5 -demoClass 0 -demoSkill 1 -demoMenu
```

`demoClass` 为0突击、1重装、2侦查、3远程；`demoSkill` 为该职业表中的0第一项、1第二项。`-demoMenu` 直接进入职业整备。交付包也可手动运行 `开始演示.ps1 -Level 5 -Class 0 -Skill 1 -Menu`。

四职业演示使用临时档，显式预置全武器、技能3级、4医疗/2弹药/2护甲、0信用点，没有伪造首通和交易历史；输入、伤害与任务规则正常。旧 `-swapHunterDemo` 仍是隔离 v4 旧模式，不用于展示本页的四职业商店。
