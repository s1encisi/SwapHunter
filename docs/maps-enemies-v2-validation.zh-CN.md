## 本轮验证了什么

1. **十二章真实几何与任务路径。** 由正式建图与部署入口创建地图，记录原始NavMesh三角形、任务点、出口、锚点、功能物件、区域与小Boss3.2米岗位净空。另存初始状态，以及隔离夹具明确打开永久门桥后的状态；开门夹具与实战结算分开记录。
2. **步行与合法Q分别核对。** 步行可达集合是锚点闭包的起点。每条新增Q连接实际调用`ValidateSwap`核对距离、真实视线、双端体积和干扰，没有把全部锚点无条件当作可达种子。第3/5/7/9章的永久目标和检查点必须步行可达，不能由Q替代断裂的楼梯。
3. **8块实际地图跳板。** 两端调用`GroundAt`确认真实地面与导航支撑，水平距离为20米；复用正式`LaunchTo`共同的`CanLaunchTo / PlanJumpV2`进行32段胶囊扫掠及落点净空检查。预检不启动投送、不消耗次数。通用操作夹具另外覆盖新按下触发、重复使用、位移与Q衔接。
4. **192个基础配装组合。** 四职业×两职业技能×两通用技能×十二章，采用真实Store.Begin产生的一级、无消费道具快照，并核对实际路径图。此项证明装配和任务可达性，不是192次战斗胜利。
5. **敌人与Boss。** 本轮命中、原型技能、设备、危险、换位与沉默响应、小Boss独立身份及最终Boss关系纳入专项；逐项结果见`map-v2-report.json`。
6. **装备与操作。** 覆盖新技能、定向盾、三把相位飞刀、道具取消与提交、近战刀拾取/取消/成功入库、机械装填和手部抓握等本轮规则。抓握修正保持真实骨链可达要求，未通过放宽判定掩盖够不到的问题。
7. **实际画面。** 审阅四张十二章拼图（48个地图视角）、14幅敌人/Boss展示、7幅装备/武器库画面，并查看地面拾刀与第12章战斗原图。地图夹具抑制AI，展示舞台与实战场景分别注明；性能场景使用真实AI。附件还包含2幅性能场景原图、新旧面积原始数据及复算结果。

这些证据来自脚本夹具、真实运行相机与实际画面审阅。没有把它们写成真人十二章完整通关、全配置平衡结论或商业美术质量认证。

## 从原始三角形复算面积

依赖Python与Shapely：`python -m pip install shapely`。在源码根目录运行：

```powershell
python .\Tools\measure_map_v2.py --baseline "..\evidence\ui-review\baseline" --candidate "..\evidence\run-01\map-v2" --output ".\area-comparison.recomputed.json"
```

将路径对应到实际解压位置。旧版和新版目录各读取`chapter-01.json`至`chapter-12.json`，新版不选择`-initial`状态。省略`--output`时输出候选目录的`area-comparison.json`。

旧分母使用全部旧三角形的投影并集；新版分别读取`walkReachableTriIndices`和`anchorReachableTriIndices`。空集合按零计算，缺失实际可达集合会报错，不回退成全部NavMesh。原始数据不被修改；`meetsTwentyTimes`采用未四舍五入的面积判断。
