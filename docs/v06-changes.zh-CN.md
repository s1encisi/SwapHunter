# v0.6 空间任务与工程升级

本轮依据十二关空间任务提案及求职导向工程方案实现。Windows Release 已通过同构建九套后台原生验证，具体通过项与待补充体验项见[验证记录](validation.zh-CN.md)。

## 保留的核心规则

22 米基础换位范围、3.5 秒基础冷却、0.08 秒准备后复核、双方朝向/生命/装备保留、双端净空、失败回滚；已有枪械、伤害、成长费用、首通解锁顺序和章节稳定 ID 保持。新增任务不依赖未解锁回刀或首通奖励武器。

## 空间任务

十二关分别围绕校准夺位、盾牌朝向、垂直上行、带敌撤离、双塔射界、危险转移、三岛搬锚、任选两仓、顶层下撤、有限断援、局部干扰与 Boss 争位编排。

- 主目标、指定必清对象和撤离点独立；仅入门章保留成功换位门槛。
- 每名计划敌人具有明确预算状态，取消未部署预算不删除存活敌人。
- 固定高台岗位保留其高度和邻近区域，非法时延期。
- 目标和区域触发锁存，并识别换位后的到达。
- 三岛接入后可以继续移动锚点；维护复位先验证全部位置，只移动任务锚点。
- 封锁装置支持真实枪械、已有爆炸和近战，不成为 Q 目标。
- 第四关凭据位于中央门前，取得后真正开放前进捷径，并保留外环选择。
- 第八关任意两匣可撤离，界面按主目标 2/2 与额外目标分别显示；第十关控制站切断尚未投入的有限增援。
- 第十一关只限制有效局部场中的换位两端，枪械和中间穿场射线不被额外禁用。
- Boss 是指定威胁；六名随从分阶段调度且并发受限，存活随从不成为默认全清条件。
- 第十二关增加永久低台的多向坡道入口与左侧外环低台，形成三处 1.4 米避险位置；本章撼地波预警改为 2.5 秒，未提高枪械伤害或改变地波基础伤害。
- 修正第三关楼梯入口、三岛出口站立邻位与第九关高塔楼梯落脚的几何冲突；实际路线结果单独记录，不以布局修改代替通过结论。

完整规则和实际编组见[任务与遭遇](encounters-v06.zh-CN.md)。

- 换位结果使用稳定原因码，中文提示不参与玩法判断；距离文案读取配置。
- 任务/遭遇资产可以在中文分章 Inspector 中编辑并校验；地图生成与物理槽位仍有明确代码边界。
- 普通构建读取现成源资产，底座重建单列 Prepare；旧构建与报告不覆盖。
- 补齐作者生成器依赖的 Git 白名单和中文作者说明，增加无 Unity 许可要求的静态 CI 配置。
- 设置保存采用临时文件、刷新、替换与备份，恢复时保留损坏原件；保存失败不显示成功。
- QA 隔离档案，源码与程序集身份关联；新规则、路线、存储、画面与性能分开报告。
- 增加 Start-Demo-v06.ps1 与 -swapHunterDemo -demoLevel 入口：每进程独立临时档，全武器/飞刀预置明确标识，正式成长、SH 检查点和 SH 设置隔离，正常战斗规则保留。

- 日志保留原有事件字段，并增加章节、帧号、位置、换位关联编号及成功落盘后的资源快照。
- 新原生双端预览、任务耐久和干扰边界，以及基于实际截图调整的标签可读性。
- 测量后引入有界闲置弹丸池；运行时导航数据在地图销毁时明确释放，暂时禁用仍可恢复。
- 修正第 3、9 关永久路线的入口/连接问题，第 7 关出口检查点避开真实掩体；通过完整十二关实际角色路线。
