# v0.6 游玩指南

《换位猎手》是离线单人 FPS 原型。Q 会交换你与敌人或相位锚点的位置；战斗收益来自落点、朝向、掩体和危险的改变。

v0.6.0 已完成同构建后台规则与完整十二关保底路线验证。本文说明当前规则和操作；前台体验、真人首通和实时性能的验证状态见[项目入口](../README.md)和[验收记录](validation.zh-CN.md)。

## 开始前

完整解压 Windows 玩家包后运行 `SwapHunter.exe`。保留同目录的 `SwapHunter_Data`、`UnityPlayer.dll`、`MonoBleedingEdge`，以及包内的构建身份文件。新候选放入新目录，保留旧版本。

首次建议完成“逐步实战教学”，再进入“相位行动”选择章节、两把已解锁武器和配件。章节主任务会变化，不能沿用“全部清敌后原路返回”的习惯。自由试招和旧模式继续保留，其任务与经济不等同于相位行动。

## 快速演示（独立临时档）

若包内附有“开始演示.ps1”，可运行 .\开始演示.ps1 -Level 2。也可在新版体验包目录使用：

~~~powershell
.\Start-Demo-v06.ps1 -ExecutablePath (Join-Path $PWD 'SwapHunter.exe') -Level 2
# 同一新版玩家的直接入口：
.\SwapHunter.exe -swapHunterDemo -demoLevel 2
~~~

-Level / -demoLevel 接受 1—12，默认第 2 关。建议依次看第 2 关盾线、第 6 关危险与破坏、第 7 关搬锚，再体验第 12 关。源码仓库中的启动脚本位于 Tools/Start-Demo-v06.ps1。

演示界面持续显示“演示档 · 不写正式进度”。新进程会新建 %TEMP%/SHD 下的独立临时档；章节可选、全武器及飞刀三级是演示预置，研究点为 0、专精为默认 0 阶，没有预填通关、最佳时间或收据。正式成长、SH 检查点和 SH 设置不读写；可以正常受伤、失败和撤离，没有无敌或跳过主任务。退出后临时资料保留供检查，下次演示不会继承它。正常启动 SwapHunter.exe 则使用正式档。

## 查看武器

在“相位行动”的“武器装配”页点选图标卡。右侧是该武器真实模型和六项基础属性，可转动查看；数字提供精确值，条形用于同项对比。点击主/副武器槽后再装备，选中已在另一槽的枪时沿用交换两槽的规则。未解锁武器可以看模型和数值，暂不能装备。背包中的弹药条读取本局实际余量。

| 输入 | 功能 |

| 左键 / 右键 / R | 开火 / 瞄准 / 装填 |
| Q | 对准存活敌人或相位锚点换位 |
| Shift / Alt / Ctrl | 冲刺 / 慢走 / 蹲伏 |
| Space | 跳跃；满足条件时翻越 |

| 1、2 / 滚轮 | 切换两把装备武器 |
| C | 定向 A 盾 |
| V / G / X | 近战 / 投刀 / 召回飞刀；主动召回需第三级研究 |

可在设置中重绑。弹药包在战术背包中使用；打开背包会暂停任务与增援时钟。

## 换位要看两端

基础距离为 22 米，成功冷却 3.5 秒，准备约 0.08 秒后还会复查目标、视线、净空与干扰。屏幕提示中的距离读取当前配置。目标必须是存活敌人或锚点；终端、数据、封锁装置、手雷和任意地面坐标都不是 Q 目标。

双方保留自己的朝向、生命和装备。你过去后通常需要转身；敌人短暂眩晕后仍会行动。换位不提供无敌、自动背刺或伤害结算。实体盾及附属碰撞体会占空间，蹲伏也不能绕过站立净空检查。

| 提示/情况 | 可采取的行动 |
|---|---|
| 超距、视线被挡 | 靠近、换一个观察角度，确认目标身体与射线 |
| 落点受阻 | 同时检查你将到的位置和目标将被送到的位置；离开窄口再试 |
| 冷却、动作进行中 | 等待冷却或动作结束；蓄能、翻越时不能 Q |
| 相位干扰 | 让双方都离开场区，或关闭对应控制器/摧毁发射器 |
| 移动或终检失败 | 本次取消；确认提示后重新选择目标，不会按成功换位扣冷却 |

局部干扰只判断两端位置。两端都在场外时，瞄准射线经过场区中间不会额外禁 Q，普通墙体仍会挡视线。空中可以换位，但落点之后要有站立区和退路；不要依赖一次普通跳跃中连续等完两次冷却。

手雷的引信和位置、已经展开的 A 盾都留在世界中。把敌人送进危险前，先确认自己将到达的位置是否安全。

## 特殊任务操作

**三岛接入。** 站在接入座附近，对另一处锚点使用 Q，将锚点换到你的原位置。锚点进入接入范围后目标锁存；接通后仍可搬走。维护终端可重复复位任务锚点，但原位被人物或障碍占用时会拒绝。复位不移动玩家、不取消接入进度，也不恢复已用大跳或增加奖励。下层维护路提供步行返回路径。

**封锁装置。** 对装置使用实际枪击、爆炸或近战，生命归零才完成目标；按 E 只会提示破坏方式。弹药用尽时保留近战路线。飞刀不是主任务必需解法。

**断援控制站。** 关闭后取消对应入口尚未生成的预算，包括预警中的增援。已经出现的敌人继续存在，不能把控制站当作清屏按钮。

**Boss 关。** 需要双高台授权、地面核心和 Boss 击败，普通随从可以遗留。随从预警与存活成员合计最多两名，Boss 死亡后取消剩余未部署随从。

## 每章的终点

| 章节 | 主线完成条件 | 撤离位置 |
|---|---|---|
| 1 相位校准 | 成功 Q 一次，击败实战守卫；训练机可提前击毁 | 前方校准出口 |
| 2 盾线缺口 | 击败两名指定盾卫；侧向突击兵可遗留 | 后方货检闸口 |
| 3 垂直通路 | 取得上层通行件 | 上层出口 |
| 4 首次撤离 | 取得门前核心凭据；可选中央捷径或外环撤离 | 对侧出口 |
| 5 交叉火网 | 左右火控节点均完成 | 中央货运出口 |
| 6 危险转移 | 两处封锁装置均摧毁 | 货舱出口 |
| 7 三岛继电 | 三处锚点接入均完成，顺序自由 | C 岛出口 |
| 8 回线仓区 | 任意两份数据达到主目标 2/2；第三份单列额外目标 | 仓区汇合出口 |
| 9 高塔回收 | 顶层取得核心后下撤 | 地面出口 |
| 10 持续封锁 | 关闭三处控制站 | 控制站货运出口 |
| 11 反相设施 | 取得核心权限；无需关闭全部场区 | 安全外环出口 |
| 12 核心突破 | 两处高台授权、地面核心、Boss 击败 | 对侧出口 |

除表中的指定威胁外，不要求全清。橙色预警和仍存活的普通敌人可能继续攻击，应区分“允许撤离”和“当前安全”。完整编组与路线说明见[十二关遭遇](encounters-v06.zh-CN.md)。

## 资源与成长

每次进入章节重置为满生命、满弹匣和对应备弹；常规携带 2 医疗包、1 弹药包，生存专精携带 3 医疗包。医疗包恢复 40 HP；弹药包为两把装备武器各补两匣备用弹药，受各自上限限制。

第 1 关有一处场地补给，通常其余关卡有两处；第 10 关只有一处，并将初始备弹减半，但仍保留满弹匣和后续补给上限。补给不会形成跨章节弹药积累。

首通奖励从第 1 关 80 点起，每关增加 15，至第 12 关 245 点。重玩第 1 关 5 点，其余 30 点；失败本次奖励为 0，已有永久成长保留。第 4 关起的可选数据仅成功带出才加 40；第 8 关由第三份数据承担这一奖励。可选目标不再统一追加两名追兵，各章风险来自对应路线、暴露或额外交战。

| 选择 | 当前收益与代价 |
|---|---|
| 突入专精 | 换位后 2.5 秒枪械增伤，随等级为 8%—32% |
| 生存专精 | 承伤减少 5%—20%，移动降低 2%—8%，多 1 医疗包 |
| 机动专精 | 移动提高 3%—12%，Q 冷却减少 5%—20%，承伤增加 3%—12% |
| 补偿器 | 散布减少 15%，装填时间增加 8% |
| 扩容备弹 | 备用弹药增加 25%，移动降低 4%；不增加弹匣容量 |
| 轻量握把 | 移动提高 5%，散布增加 12% |

专精等级 0 已有基础效果，只当前选中的专精生效；升级依次花费 120/220/320 点。飞刀研究依次为 80/140/220 点，解锁命中沉默、范围沉默和主动召回。第 8 关主线不要求研究回刀。部署后不能修改永久配装。

## 留好慢速退路

重武器、生存专精和扩容备弹会叠加降低移动。第 3、5、9、12 关的楼梯/坡道，以及第 7 关下层维护路，用于在敌人提前死亡、锚点搬走或大跳耗尽后继续步行；这些路线仍需按[验收记录](validation.zh-CN.md)确认实际通过情况。

Boss 撼地波不能靠 A 盾挡住。普通平地跳跃不是可靠反制；应提前选择永久高位、确认可换目标或保留一次大跳。第 12 关有三处一次性大跳、三处 1.4 米永久避险台及更高平台；低台具有多个坡道入口，左侧外环也有独立低台。相位行动第 12 关的撼地波预警为 2.5 秒，其他技能和经典模式不统一改成这一时长。不要假设任意站位都能慢速步行赶到安全区。

退路脚本会预先选定完整导航路线、移除随从并标记大跳已用；默认在生存三级、轻机枪和扩容备弹配装下冲刺，预警后固定等待 0.5 秒再移动。它记录实际站稳高度与原生受伤结果，但这不是初见玩家的观察、反应或完整 Boss 战成绩。具体结果仍以对应构建的验收记录为准。

设置保存失败时应保留提示并重试，不能把仍可继续游玩当作已成功落盘。成长结算失败会锁定本次结果供重试，不重复兑现奖励。反馈问题时记录版本/构建身份、章节、操作顺序、提示文字及截图；不要用删除原存档作为首选排查方法。
