# 换位猎手 SSU-01：系统协同升级游玩说明

本说明面向当前升级分支，规则版本 3。它与已发布的 v0.6.0 试玩包分开交付。基础价格、奖励、武器伤害、技能等级数值保持不变。

## 1 从哪里开始

完整解压 Windows 包，保留 `SwapHunter.exe` 与同目录 `SwapHunter_Data` 等文件。

- 双击 **快速体验.cmd**：进入独立演示整备页，可浏览全部职业、武器和章节。演示预置不写正式成长。
- 双击 **SwapHunter.exe**：进入正式成长，按原有保障配置开始。
- Unity Hub 查看源码：添加 Source 包内的 **Game** 文件夹，使用 **Unity 6000.3.25f1**。

## 2 先看配置，再试用，再自行采购

在关外整备查看武器、职业技能或通用技能，进入定向试用。试用启动独立窗口；原整备窗口等待试用结束。

默认试用等级对应这次购买或强化的实际结果。未拥有技能按一级试用；强化按下一等级试用。另有明确标识的同阶比较，避免把三级体验误认为一级购买效果。

试用有近距转场、长视线两种情境，可以随时结束。观察出弹、命中、装填、控制和承伤，不以单一伤害分数判断扫描等信息能力。结束后回到原商品，再根据当前价格与余额决定是否购买。

试用不授予正式货币、技能、库存或通关记录。异常关闭时恢复整备；没有结果会明确提示，不自动购买或补偿。返回时若当前档案读取失败，采购与部署保持锁定，重新读取成功后恢复操作。

## 3 配装路线怎么用

八条路线用于说明武器、职业技能和通用技能如何分工，不是强度排名。它们不会自动发装备或代购。

| 职业 | 路线 | 关键配合 | 需要承担的代价 |
|---|---|---|---|
| 突击 | 突入撤离 | 冲锋枪＋双管、快速机动、A盾 | 先抢位后攻击；盾留在原地 |
| 突击 | 近身控场 | 卡宾＋泵动、震荡突击、飞刀 | 近距控制换出手机会，仍受盾面与冷却限制 |
| 重装 | 机动补弹 | 机枪＋卡宾、快速装填、飞刀 | 长火力和转场分工，防护能力需要取舍 |
| 重装 | 定点守线 | 机枪＋重突、阵地加固、A盾 | 离开阵地失去加固，空间技能需要走位处理 |
| 侦查 | 信息择线 | 三连发＋射手、战术扫描、A盾 | 提前获知位置不等于穿墙射击或穿墙换位 |
| 侦查 | 关键单点 | 射手＋栓狙、精确射击、飞刀 | 单次输出换取小弹匣和射后等待 |
| 远程 | 直击集火 | 线圈＋标记器、遥控爆破、A盾 | 标记支援枪弹；爆破是独立用途，不吃标记 |
| 远程 | 封锁拆解 | 榴弹＋卡宾、区域封锁、飞刀 | 范围压力与控制结合，保留自伤风险 |

路线会展示拥有、上架、资格与缺项成本。全部合法并处于整备时，查看替换差异后应用；缺项可转到商品。技能仍是一项职业技能加一项通用技能，普通近战独立。

前 3 章先理解保障配置；第 4—6 章比较新枪、技能强化和补给预算；第 7—12 章尝试横向解法。重装后期仍围绕现有枪械形成两条打法，不额外伪造新枪解锁。

## 4 Q 与其他动作怎么衔接

- 同一帧发起有效 Q 与新的射击、近战、投掷时，Q 优先；没有发出的攻击不扣弹、不排队补发。初始 Q 检查失败则照常处理其他输入。
- 已经发生的伤害和弹药转移保留。三连发尚未出膛的部分在 Q 接受时取消，不因随后 Q 失败而复活；原有射后间隔继续存在。
- 正在装填时接受 Q：准备期间冻结剩余装填。换位成功取消未完成装填；末端检查失败恢复剩余时间。准备期间新的装填、切枪和主动交互不排队。
- 正在蓄能的线圈枪阻止 Q；先松开取消蓄能。未出膛不扣弹。
- 已存在的飞刀可以召回、遥控炸药可以引爆；新的投掷、放盾或区域施放等待 Q 准备结束。刀追踪玩家当前实际位置，炸药在原世界位置爆炸。
- 机动、扫描、精确射击准备等自身状态继续计时；护盾、阵地、区域和抛射物保留世界位置。暂停冻结动作，死亡或离场清理未完成动作。

## 5 标记、护盾和 Boss 的统一规则

相位标记持续 5 秒，命中当次先结算伤害再施加标记；后续枪弹和普通近战增伤 20%。爆炸、飞刀、区域持续伤害不享受标记。敌人盾面、Boss 能量盾和玩家 A盾分别有自己的规则，不能用“都是盾”推导所有伤害的处理方式。

Boss 的短硬直停止普通移动和基础攻击，空间技能预告与执行继续走时。飞刀沉默可打断尚在预告的空间技能；已经进入执行的技能会完成整段，包括后续脉冲、激光或弹幕。沉默阻止下一空间技能，不是让 Boss 完全停止攻击。

沉默 3.2 秒，之后 4.5 秒抗性；期间重复命中不续时。下一空间技能同时等待收招和沉默结束。能量或生命跨阶段会立即更新资源，但当前已预告或执行技能保留起手时的参数，下一动作使用新阶段技能池。

## 6 看懂补给和三类记录

图鉴、实际装弹与弹药包读取同一份有效基础参数；扩容配件增加备弹上限，不增加弹匣。弹药包按两把已装备武器各补两个有效基础弹匣，实际补入受备弹空间限制。

| 记录 | 说明 |
|---|---|
| 采购回执 | 实际购买、付款、余额与库存；重复请求不重复发货 |
| 尝试记录 | 每次进入到死亡、放弃或成功，记录有效时间、暂停、医疗实回、弹药实补、护甲实吸 |
| 成功持久化结算 | 奖励、首通与最终实际永久消耗；失败尝试的临时使用不等于永久扣除 |

失败重试恢复采购后的出发库存；累计尝试时间包含失败过程，最佳成绩仍按原先成功一局计时。记录仅写本机 `Playtests/attempts-*.jsonl`，包含 Normal / Trial / QA 标识和规则版本。缺少结束事件代表未完整记录，不能当作零成本或通关成功。记录写入失败会显示提示，资产仍以保存成功的回执为准。

## 7 推荐体验顺序

1. 整备页选择一条路线，先看技能和武器的职责、缺项与替换内容。
2. 对一个商品分别进入近距或长线试用；比较时保持等级和其余配置一致。
3. 回到商品，自行决定采购或继续使用已有配置。
4. 第 8 章尝试两仓撤离与第三仓支线，观察实际弹药、道具和时间；第 10 章观察提前关站与未来增援的关系。
5. 第 12 章观察短硬直、沉默和 Boss 已承诺技能的区别。结算后查看最终扣除与累计尝试时间。

试用、自动化夹具与真人完整通关是不同证据。本轮具体通过项以包内 `validation-status.json` 和专项报告为准；不预设数值优化幅度。
