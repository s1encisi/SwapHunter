# Showcase tools

These optional Python scripts process captures from the SwapHunter player. They are not needed to build or play the game.

- `make_showcase.py`: historical v0.4 screenshot presentation.
- `make_trailer_v05.py`: Blender video-sequencer timeline from local gameplay media.
- `mix_capture_audio.py`: reconstructs trailer audio from emitted game sound events.
- `verify_trailer.py` and `verify_video_project.py`: inspect rendered media and timeline portability.

Inspect each script's argument parser for the required local media paths. Blender/FFmpeg and Python imaging dependencies are authoring tools, separate from the Unity game. Keep media beside portable timelines and retain font/license notices. Screenshot slideshows, scripted captures and concept art must be labelled as such; captured animation sequences are not frame-rate benchmarks.
