# Original Blender assets

The Unity project uses the included GLB files; opening and building it does not require Blender.

- `generate_v04.py` authors ten weapons, operative arms and four robots.
- `generate_combat_v05.py` reuses those helpers to author the phase knife.
- `blend/` retains editable original assets; `weapon-lineup.blend` is an older presentation scene.
- Runtime exports are in `Game/Assets/_SwapHunter/Art/BlenderModels/`.
- `render_lineup.py` produces an optional authoring preview.

Geometry uses metres, with author X-right/Y-up/Z-forward mapped to Blender `(x,-z,y)`. Weapons provide functional markers and articulated nodes; Unity authors gameplay colliders separately from visual geometry. The two base guns are generated by the adjacent Three.js tools.

To regenerate, run the generators in Blender background mode. They overwrite selected authoring outputs, so use a separate copy when experimenting. Preserve Unity `.meta` files to retain asset references. `generate_v04.py -- --only weapon_05 --render` selects a single asset; `generate_combat_v05.py` must remain beside it.

`python Tools/BlenderAuthoring/validate_exports.py` checks exported GLB headers, axes, functional nodes, triangle counts and editable sources against the 15-asset manifest. It writes a local `asset-contract-report.json`; the extra knife is described separately by `combat-v05-manifest.json` and checked by the Unity integration suites.

The geometry and generators use the root MIT license. Original sources can contain editor-local preview paths; select your own output directory before rendering a moved source. Studio previews illustrate models; the root README separately labels real game screenshots.
